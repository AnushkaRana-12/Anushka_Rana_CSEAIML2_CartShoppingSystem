# Anushka_Rana_CSEAIML2_CartShoppingSystem
Cart Shopping System is a digital solution for ration shops that lets customers place orders via screen, pay online or offline, and collect items using QR codes. Built with HTML, CSS, JavaScript, and Node.js, it streamlines billing and enhances staff efficiency.
